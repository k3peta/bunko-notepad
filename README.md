# bunko-notepad

単一HTMLファイルで動く、縦書き原稿用の小さなノートパッドです。

本文編集はブラウザ標準の `textarea` を使い、入力・IME・カーソルの安定を優先します。厳密な文庫風組版はプレビュー側で確認する方針です。

## 起動

`index.htm` をブラウザで開きます。

`index.html` は `index.htm` へのシンボリックリンクです。

## 主な機能

- 縦書き本文編集
- 一行文字数: 39 / 40 / 41
- 一頁行数: 15 / 16
- 欄外行番号
- ページ区切り線
- 原稿用紙風の薄い枡目
- テキストファイルの読み込み・保存・別名保存
- 検索・置換
- 正規表現検索
- 半角 `# ` / `## ` / `### ` による見出し抽出
- 見出しリストのドラッグ＆ドロップによる章順入れ替え
- 見開きプレビュー
- プレビューでの句読点ぶら下げ
- プレビューでのルビ表示
- プレビューでの縦中横

## 記法

### 見出し

行頭に半角 `#` と半角スペースを置くと見出しになります。

```text
# 大見出し
## 中見出し
### 小見出し
```

全角 `＃` は見出しとして扱いません。

### ルビ

プレビューでは青空文庫風のルビを解釈します。

```text
｜東京《とうきょう》
東京《とうきょう》
```

### 縦中横

プレビューでは次のような短い半角列を1マス内の横組みにします。

```text
12
3.5
!?
!!
```

## ショートカット

- `Cmd+S` / `Ctrl+S`: 保存
- `Cmd+Shift+S` / `Ctrl+Shift+S`: 別名保存
- `Cmd+F` / `Ctrl+F`: 検索欄へ移動
- `Cmd+G` / `Ctrl+G`: 次の一致を1件置換
- `Cmd+Z` / `Ctrl+Z`: 戻る
- `Cmd+Shift+Z` / `Ctrl+Shift+Z`: やり直し
- `Cmd+T` / `Ctrl+T`: 現在行を `# ` の大見出しにする

## 設計メモ

本文編集欄では、句読点ぶら下げを完全には再現しません。`textarea` 内では Chrome の縦書き組版が通常の本文要素ほど細かく効かず、無理に自前表示を重ねるとカーソル位置やIME入力が不安定になるためです。

そのため、本文欄は「書くための安定した画面」、プレビューは「文庫風の見え方を確認する画面」として分けています。

## 現在の制限

- 本文編集中の句読点ぶら下げは目安です。
- プレビューの組版は簡易実装です。
- ルビや縦中横はプレビュー専用です。
- 保存先の上書きは File System Access API 対応ブラウザで動作します。
- ブラウザや環境によってファイル保存の挙動が異なる場合があります。
